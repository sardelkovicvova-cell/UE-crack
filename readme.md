**Skybox Naming Rules**

Side abbreviations:

* **Bk** = Back
* **Dn** = Down (Bottom)
* **Ft** = Front
* **Lf** = Left
* **Rt** = Right
* **Up** = Up (Top)

### Image Requirements

* Use **one single image file** for all 6 sides of the skybox.
* The image file must have the **`.png`** extension.
* Do not create the same image for every side.
* Do not create any additional folders.

### Folder Location

* Place the image directly inside the **`Skyboxs`** folder.
* Do **not** create a custom folder with the skybox name.

### Naming Format

* The skybox name is the PNG filename without the extension.
* The file should be named:

`<name>.png`

### Example

If the skybox name is **test**:

File:
`Skyboxs/test.png`

In this example:

* `test` is the skybox name.
* `test.png` is the image file.
* The file is placed directly inside the `Skyboxs` folder.
